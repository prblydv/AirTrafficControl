# Shared timed ground traffic — verification record

1. Implementation requested: saved proposal 1 only. New `AirTrafficControl/GroundTrafficPlanner.swift` plus its `Simulation.swift` integration replace ordinary taxi congestion-cost forecasts with executable timed trajectories. Xcode source registration and the project generator include the new file. No dependencies, services, backend, payment setup or publishing were added.
2. Search labels include node, incoming edge and safe interval. Trajectories contain explicit waits and acceleration/deceleration profiles. Conservative swept convex aircraft footprints cover edge swaps, unjoined junction crossings and turning space. Planning, validation and commit run synchronously on the main actor against one immutable snapshot; later requests see earlier commits.
3. Actual held positions remain occupied. Route, position, heading, phase, readiness and graph changes withdraw affected/dependent plans. Independent schedules keep their slots. Normal crossing requests still stop until tower approval; actual runway rolls retain tower authority and incident consequences.
4. Existing physical tug recovery and already-overlapping starting configurations retain guarded local separation. Passing-place admission checks future exit feasibility through the same planner, tries the opposite yielding direction if necessary, and rotates through every candidate across bounded attempts (two feasibility searches per attempt, 3,000 expansions each). Normal searches are bounded to 18,000 expansions and a 240-second planning horizon. These bounds and conservative footprints trade capacity/completeness for bounded work; no global deadlock-free or fleet-optimal claim is made.
5. Full data-driven airport packaging, typed topology compilation, calibrated continuous motion, corridor batching, service-dependency recovery/fairness, capacity-aware arrivals and service dispatch remain separate saved proposals. Source tracing and background remain unchanged.
6. Repeat checks: `python3 scripts/check_ground_traffic.py`. The helper compiles the shared Swift sources once and runs planner, ATC authority, surface safety, arrival/service/departure lifecycle and three-seed fleet-completion checks. Exact accepted results and preserved-file hashes are saved alongside this record after final verification.
7. Algorithm reference: [Phillips and Likhachev, SIPP: Safe Interval Path Planning for Dynamic Environments](https://www.cs.cmu.edu/afs/cs/Web/People/maxim/files/sipp_icra11.pdf). This implementation uses safe-interval search concepts with conservative swept resources and its own ground-motion execution; it does not inherit a multi-agent global deadlock-freedom guarantee.
